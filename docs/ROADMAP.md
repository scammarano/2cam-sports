# Entregas

- **S0 / 0.1.0 actual:** motor de puntuación configurable + servicio local + interfaz web de prueba + controles con límite 3 + tests. JSON de un escritor, polling. El ZIP de Actions es una previsualización técnica para Node, no instalador cPanel.
- **S1:** portal PHP/MySQL/AdminLTE multiempresa, CRUD completos, torneos/jornadas, participantes, programación y conflictos; instalador web, backup, migraciones y actualizador ZIP; logs exportables. Conservar motor con pruebas de conformidad si se implementa en otro lenguaje.
- **S2:** persistencia local transaccional, autoridad del encuentro, sincronización con portal y outbox. Gateway WSS, replay y fallback incremental con retención. Contrato Signage revisando código real.
- **S3:** aplicación remota Android, descubrimiento LAN, QR, reconexión persistente y APK compilada mediante Actions. Adaptador de pantalla en repositorio Digital Signage; pruebas físicas Fire OS 5/API22, Wi-Fi sin internet, varios controles y visores, publicidad y latencia medida.
- **S4:** iPad/iPhone y Apple Watch, controles físicos/Bluetooth si el hardware lo permite; reportes avanzados y reglas adicionales.

Pendientes de confirmar: disciplinas adicionales, orden de saque/receptores en dobles, política de auxiliares cuando hay varias pantallas de un encuentro, hardware del servicio local, hosting/gateway, repositorio y versión real de Signage, firma móvil, reglas específicas por torneo y formatos homologados frente a variantes internas.

No modificar reglas de una partida iniciada silenciosamente. Las futuras correcciones administrativas de formato/resultado requerirán revisión, permisos, motivo y auditoría.
