# Reglas y formatos

Consulta: 15 de octubre de 2026. Fuentes primarias:

- ITF, Rules of Tennis 2026, reglas 5–7 y métodos alternativos: https://www.itftennis.com/media/7221/2026-rules-of-tennis-english.pdf
- FIP, Rules of Padel, revisión aplicable 01.01.2026, regla 1: https://www.padelfip.com/wp-content/uploads/2025/12/FIP_Rules-of-Padel-1.pdf

Se implementa puntuación habitual, ventaja, sin ventaja, sets con tiebreak y desempate de partido. FIP contempla también Star Point: tras el primer iguales pueden ocurrir dos ventajas fallidas; el siguiente punto tras el tercer iguales decide el game. No se infiere una sola política para toda la disciplina: el organizador selecciona formato explícitamente.

La configuración permite variantes de club (por ejemplo, proset a 8 con TB en 8–8 o 7–7). No se etiquetan como una regla oficial universal. Las reglas del encuentro son copia independiente de la plantilla.

No confundir:

- Mejor de 3 sets: hacen falta 2 sets ganados.
- Mejor de 5 sets: hacen falta 3 sets ganados.
- Set a 3 games: set corto; no es un partido al mejor de 3 sets.
- 2 sets + supertiebreak: con 1–1, desempate a 10 (o el objetivo configurado), diferencia de 2. Es un reemplazo del último set, no un game agregado a 6–6.
- Tiebreak del set: a 6–6 por defecto; el ganador registra 7–6 y se conserva el resultado de puntos del tiebreak por separado.

Los tests comprueban las reglas de marcador, no certifican cumplimiento arbitral integral. Orden de receptores, selección de lado al punto decisivo, cambios de lado y rotación individual en dobles requieren una siguiente entrega.
